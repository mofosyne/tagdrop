          This browser's signing identity (the ML-DSA-44 keypair behind signer_id) only lives in this
          browser's local storage — a different computer, browser, or profile gets a brand-new identity, breaking
          continuity with anyone who already trusts your old signer_id. Export makes a
          passphrase-protected backup file you can move to another browser/computer and re-import there via
          Import signing identity — keep it like a password: anyone with the file and its
          passphrase can sign as you.

Files on this Paper

    

      Each file gets its own QR code. HTML files can reference other files on the
      same or different papers using absolute tagdrop:// links —
      the app intercepts these and serves the cached bytes inline, so images,
      audio, and SVGs load without a network connection:

      <img src="tagdrop://@ROOTHASH/photo.jpg">

      <audio controls src="tagdrop://@ROOTHASH/song.mid">

      Slugs can contain / to mimic folder paths
      (e.g. images/photo.jpg) — they are matched as plain strings.
      A file too large for one QR code is automatically split into multiple
      sector codes, same as the Single File tab.
