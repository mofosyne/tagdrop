➕ How to add your drop

If you've placed a TagDrop code in a public space, open a pull request to add it to the community database. Each entry needs:

  1. Cache ID — the cache_id of your TagDrop code. You can copy it from the app's inspect screen (tap the ⋮ menu on a scanned item → Inspect) or from the web generator's output panel. It looks like a3f8b2c1d4e5f6a7 (16 lowercase hex characters).
  2. Coordinates — WGS84 latitude and longitude of the physical location where you placed the code.
  3. A short hint — a clue for the finder, e.g. "Behind the loose brick on the north wall". Keep it findable without being a spoiler.
  4. Optional: a longer description (directions or context), a status ("working" / "broken" / "unknown"), and a status_updated date.

Add your entry to docs/db/drops.json in the TagDrop repository and open a pull request. The entry format is: 

{
  "id": "a3f8b2c1d4e5f6a7",
  "lat": 51.5007,
  "lng": -0.1246,
  "hint": "Behind the loose brick on the north wall",
  "description": "Pedestrian underpass, north face of the arch, eye level",
  "status": "working",
  "status_updated": "2026-07-03"
}

🗂 Run your own source feed

You can host a drops.json feed at any URL and share it with your community. Anyone with the TagDrop Android app can add it via Sources → Add source and see your drops on their map. See the SPEC §17 for the full schema — including related_sources for cross-linking feeds.
